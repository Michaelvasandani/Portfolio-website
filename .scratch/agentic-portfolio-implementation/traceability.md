## Audit rule

The package passes the planning audit only when automated parsing finds the same set of requirement IDs in this matrix and the specification, every ID occurs in at least one implementation ticket, every ticket lists only specification IDs, every `Blocked by` target exists and precedes its dependent ticket, every linked local artifact exists, and no human-owned action lacks a runbook checklist.
